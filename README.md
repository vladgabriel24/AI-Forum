# AI-Forum

This project's purpose is to create a cloud application in which users can use multiple LLMs for a single prompt to manage and utilize different point of views in order to provide a fortified answer.

The main idea inside this workflow is to use an LLM to compare the viewpoints of each queried LLM based on the common aspects extracted from the responses using ABSA framework.
